# 医学 LLM Teacher 项目 — 权威数据（所有文件必须引用此文件的数字）

> **本文件是所有面试材料的唯一事实来源。其他文件中的数字如果和本文件不一致，以本文件为准。**

---

## 一、模型配置

| 项目 | 值 |
|------|-----|
| Base Model | Qwen3-8B |
| Teacher Model | **DeepSeek-v4-pro**（不是 Qwen3-72B） |
| 训练精度 | QLoRA 4bit NF4，**bnb_4bit_compute_dtype=torch.bfloat16**（训练时前向/反向用 BF16） |
| 部署精度 | **float16**（实际启动命令 `--dtype float16`，merge 后全精度 FP16 推理） |
| 推理框架 | vLLM 0.21.0 |

## 二、训练硬件

| 项目 | 值 |
|------|-----|
| 训练 GPU | **RTX 5090 (32GB)** 单卡（不是 2×4090） |
| 部署 GPU | RTX 5090 (32GB) 单卡 |

## 三、训练参数

| 项目 | 值 |
|------|-----|
| LoRA rank | 16 |
| LoRA alpha | 32 |
| LoRA dropout | 0.05 |
| target_modules | 全部 attention + FFN 线性层 |
| SFT learning rate | 5e-5, cosine schedule |
| SFT epoch | **1 epoch**（不是 3） |
| SFT effective batch size | 16（micro_batch=4 × accumulation=4） |
| SFT max_seq_length | 2048 |
| DPO beta | 0.1 |
| DPO loss | sigmoid |
| DPO epoch | 1 |

## 四、数据规模

| 项目 | 值 |
|------|-----|
| 原始数据 | HuatuoGPT2-SFT-GPT4-140K 子集 |
| Teacher 生成 | ~85K 条（DeepSeek-v4-pro 生成） |
| Judge 过滤后 SFT 数据 | **55,000 条**（通过率 64.7%） |
| SFT train | 55,000 |
| SFT val | 2,000 |
| DPO pool | 13,000 |
| DPO 训练对 | **9,841 对**（约 10K） |
| DPO chosen | Teacher（DeepSeek-v4-pro）生成的答案 |
| DPO rejected | SFT 模型采样的回答 |

## 五、评测体系

| 项目 | 值 |
|------|-----|
| Judge 模型 | DeepSeek-v4-pro |
| 评测维度 | **8 维度**（准确性25%、安全性25%、完整性10%、相关性10%、医学规范10%、可读性10%、引用准确性5%、免责声明5%） |
| 人工对标 | 200 条，accuracy Spearman 0.78，safety 0.62 |
| Fleiss' Kappa | ~0.6（accuracy 维度） |

## 六、vLLM 部署参数

| 项目 | 值 |
|------|-----|
| max-model-len | **4096**（不是 8192） |
| gpu-memory-utilization | 0.90 |
| dtype | **float16**（实际启动命令 --dtype float16） |
| max-num-seqs | **16**（饱和并发点） |
| enable-prefix-caching | true |

## 七、压测数据

| 项目 | 值 |
|------|-----|
| 吞吐 | 877 tok/s |
| TTFT | 42ms（单用户） |
| TPOT | ~9-15ms |
| 并发饱和点 | **16 并发**（不是 32） |
| 16 并发时 TTFT | ~100ms |
| p99 延迟 | ~95ms（16 并发时） |

## 八、项目定位

| 项目 | 值 |
|------|-----|
| 项目状态 | 后训练技术验证 + 可演示原型（不是生产上线） |
| 已完成 | Teacher 数据生成、SFT、DPO、LLM-as-Judge、LoRA merge、vLLM 部署、压测 |
| 未完成 | PPO/GRPO/RLVR/OPD、Reward Model 训练、Docker 容器化、K8s 编排、灰度发布、A/B 测试 |
